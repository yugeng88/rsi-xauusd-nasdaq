# Panduan GitHub Pages (iPhone)

Repository: `yugeng88/rsi-xauusd-nasdaq`

1. Ekstrak `RSI_XAUUSD_NASDAQ_v2_GITHUB.zip` di aplikasi Files.
2. Buka https://github.com/yugeng88/rsi-xauusd-nasdaq
3. Tekan **Add file** → **Upload files**.
4. Pilih seluruh file hasil ekstrak: `index.html`, `README.md`, `GITHUB_PAGES_ID.md`, dan `.nojekyll`.
5. Scroll ke bawah, isi pesan commit (misalnya `Update RSI dashboard`) lalu tekan **Commit changes**.
6. Buka **Settings** → **Pages**.
7. Pada **Build and deployment**, pilih:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
8. Tekan **Save**.
9. Tunggu deployment, lalu buka:
   https://yugeng88.github.io/rsi-xauusd-nasdaq/

Jika GitHub Pages sudah aktif dari versi sebelumnya, biasanya cukup upload file baru dan commit. Tidak perlu mengubah pengaturan Pages lagi.
